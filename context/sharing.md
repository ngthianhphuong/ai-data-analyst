# Où et comment partager les résultats

À adapter à votre organisation.

| Canal | Destination | Format |
|---|---|---|
| Email | claire@example.com | Brouillon Gmail à valider avant envoi |
| Slack | #service-client | Message court + graphique principal, après validation |
| Google Docs | Dossier Drive « Analyses » | Rapport complet avec graphiques |
| Google Slides | Dossier Drive « Analyses » | 4 slides : conclusion, preuve, cause, action |

Règles :
- Ne jamais envoyer un email ni publier sur Slack sans le « ok » explicite de l'analyste.
- Ne pas partager si `scripts/verify.py` renvoie un contrôle BLOQUANT.
